## ✨ Features
| Feature | Description |
|---------|-------------|
| 🏠 Dashboard | Today + monthly + yearly totals at a glance |
| ➕ Add Expense | Quick add with 12 categories + one-tap common expenses |
| 📅 Monthly View | Category pie chart, daily pattern, all transactions |
| 📆 Yearly Report | Month-by-month bar chart, yearly category breakdown |
| 💡 Insights | Smart auto-tips based on your actual spending patterns |
| ⚙️ Budget | Set monthly budgets, track how much is remaining |

## 🛠️ Tech Stack
Python · Streamlit · Pandas · Matplotlib

## 🚀 Run Locally
```bash
git clone https://github.com/sneha7870/expense-tracker
cd expense-tracker
pip install streamlit pandas matplotlib numpy
streamlit run expense_tracker.py
```
